# 朝の森と川 / Morning Forest

木漏れ日の差す朝の渓流を、ブラウザの中で歩いたり映像として眺めたりできる 3D 作品です。
Three.js (WebGL2) 製で、インストール不要です。

## 遊び方

```bash
npm install
```

```bash
npm run dev
```

表示された URL を開き、「森を歩く」または「映像で見る」を選びます。

| 操作 | 内容 |
| --- | --- |
| W A S D / 矢印 | 移動 |
| マウス | 見回す(クリックで視点操作を開始) |
| Shift | 走る(動物は逃げます) |
| C | 探索 / 映像モードの切替 |
| N | 映像モードで次のカットへ |
| M / H / Esc | 音の切替 / 表示を隠す / メニュー |
| タッチ | 画面左側ドラッグで移動、右側ドラッグで見回す |

画質はメニューで 低 / 中 / 高 / 最高 から選べます(URL に `?q=low` などを付けても指定できます)。

## 中身

- **地形と川** — 解析的な河道と高さ関数から生成。落ち葉・苔・川石・泥・岩の PBR 地面、流れに沿う水面、対岸の映り込み、水深による透明感、水底のコースティクス。
- **森** — 手続き生成の広葉樹・針葉樹を 3 段階の LOD でインスタンス描画。葉の透過光と風の揺れ。
- **下草** — Poly Haven の実写スキャン(CC0)の岩・シダ・低木・倒木・切り株、GPU 生成の草。
- **光** — 低い朝日、影から計算する光の筋(ボリューメトリックライト)、谷にたまる朝もや、AO、ブルーム、被写界深度。
- **動物** — ニホンジカ(牡・牝・子、採食/警戒/逃走)、ヤマメ、セキレイなどの小鳥、トビ、蝶、キツネ。
- **音** — 川・風・鳥の声・足音をすべて Web Audio で合成(音声ファイルなし)。
